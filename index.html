How it works

1. Build the layout (Edit layout)

  • + Building or + Parking, then drag on the canvas to draw a rectangle.
  • Select it and drag a corner to resize. Drag a + on any wall to pull out (or push in) a section. Double-click a corner to remove it.
  • + Zone, then drag to draw a zone. Name it and pick a color on the right. Drag its handles to resize.
  • A pink line appears, and the shape snaps, when an edge or center lines up with another zone or wall.

2. Assign people (Assign people)

  • Add people on the right, then drag them onto a zone.
  • Drag someone to another zone to move them, or back to the list to take them off the map.
  • The layout is locked in this mode so nothing shifts by accident.

3. Share

  • Share gives you a picture of the map with a legend.
  • File → Save project file makes a file another manager can open here to get the same map.
