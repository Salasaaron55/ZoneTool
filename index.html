How to use

Most areas are already outlined — click one and type a manager's name to assign it and color-code it.

For anything not outlined, click New Zone, click points around the area, then press Enter.

Export Image gives you a screenshot-ready map + legend to share. Export Data saves a file you can send to other managers or use as a backup — they can Import Data on their own computer to see the same zones.

Changes save automatically in this browser, but only on this computer.
